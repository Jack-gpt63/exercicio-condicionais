# Repositório de etapas em uma maratona

&mdash; Esse repositório utiliza encadeamento com if para verificar etapas de uma maratona.
Para utilizar precisa utilizar o LiveServer e iniciar um servidor local, assim que você for para o navegador as perguntas aparecerão, caso uma resposta não corresponder o processo não vai continuar. 

# Extras

&mdash; No final do código a comentarios de código, eles são desafios que podem ser colocados no código. O primeiro é colocado logo no inicío, O segundo é o colocado no lugar da variavel "tempo" e o terceiro é colocado no final, junto do pace e das categorias.
